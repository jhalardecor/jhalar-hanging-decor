Theme

Theme controls are mapped to the live page like this: Colors -> brand, buttons, header, footer & backgrounds. Fonts & Text -> heading font/weight/letter spacing/line height, body font/weight/letter spacing/line height. Layout -> rows & columns per section, card radius, shadows, reveal motion. Inside Every Section -> per-section gaps & padding. Every value applies instantly in the preview - no reload needed.

Fonts & Text

Fonts are self-hosted in assets/fonts/ (offline-ready, fast). Upload your own .ttf / .otf / .woff / .woff2 files in the Media tab - they appear here automatically and render fully. Other choices fall back to system fonts.

Readability tip: leave title sizes on Auto so the site stays readable on phones, tablets and desktops. Set a fixed size only if you want one size everywhere.
