# JHALAR catalogue publication record

## Owner instructions

On 7 September 2026 the owner requested: **“update it on live site”**, following the 20-name proposal sheet and its photo-based descriptions. This is the publication approval for the reviewed proposals; the 15 already labelled images on `main` are retained with their existing series and colour spelling.

When asked how to handle `Products_0027`, the owner chose **“Keep it separate”**. It remains a separate catalogue item from the labelled Shobha red/yellow/white image. No unverified difference in size, construction or pack quantity is asserted. Distinct catalogue references disambiguate the entries in cards, details and WhatsApp enquiries.

## Scope and approval method

- 35 catalogue entries using all 35 source images from main commit `1eebcf6dbce090c40226379eabe70f71ac6a1d77`.
- 18 series, 24 colour labels and 34 distinct series/colour pairings.
- JH-027 and JH-035 intentionally share **Shobha Series — Red Yellow & White** but use different source images and references.
- Reference numbers are website catalogue identifiers, not claims about pre-existing manufacturer SKUs.
- Owner-reviewed assignments are stored in `content/product-naming.json` under `approvedProducts`. Approval binds each ID to its exact series, colour, original photo and display image.
- Confidence remains null for human-reviewed entries; no AI confidence percentages were invented. Automatic classifications still require the independent 85% threshold.
- “dark pink” and “green red & White” retain the original label spelling. No silent colour-name cleanup is performed.
- Descriptions describe visible arrangement, colour and finish only. Material composition, dimensions, weight, sound, durability, stock and pack quantities are not certified.
- The original JPEGs are retained. WebP display derivatives are generated for the website without changing the original product filenames.
- 7 September 2026 (late): an optional `gallery` array was added to product records for listing-style popups (extra photos per product; first extra photo also swaps in on card hover). Gate rule: every entry must be a local image path under `assets/images/`; anything else is rejected. All 35 approved bindings, names and images are unchanged. Video support is not yet implemented.

## Release procedure

Run `npm test`, `npm run validate` and `npm run naming:review`, then verify the catalogue and enquiry references in a browser. Publish via a pull request from the session branch to `main`; deployment is complete only after GitHub Pages has built and the deployed catalogue is verified.
